An entry for make.fun's **Notes From a Passive-Aggressive Fridge** bounty: one funny passive-aggressive note that a smart fridge leaves for its owner — a single line, dry, petty and specific, the sort of thing a smug appliance would put on its door screen.

The note on the door screen:

> You stood here at 3 a.m. with the door open, eating shredded cheese straight from the bag. I said nothing. I'm saying it now.

## Run

Node 22, no dependencies. The program copies the shipped `entry.txt` into the output directory, byte for byte:

```sh
MAKEFUN_OUTPUT_DIR=/output node main.ts
```
